# BookShelf — estante de livros

Versão web simplificada do BookShelf: uma estante pessoal de livros em formato de log de terminal. Organize por status (lendo, lido, quero ler), adicione e remova livros — tudo salvo no navegador.

Demo: _adicionar link do GitHub Pages aqui após publicar_

## Funcionalidades

- Listar livros com filtro por status (`--todos`, `--lendo`, `--lido`, `--quero-ler`)
- Adicionar livro (título, autor, status)
- Remover livro
- Dados persistidos no `localStorage` do navegador

## Tecnologias

HTML, CSS e JavaScript puro — sem frameworks ou build step.

## Como rodar localmente

Só abrir o `index.html` no navegador, ou publicar via GitHub Pages (Settings → Pages → branch `main`).
